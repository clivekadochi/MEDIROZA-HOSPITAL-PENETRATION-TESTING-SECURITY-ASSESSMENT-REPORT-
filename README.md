# MEDIROZA HOSPITAL-PENETRATION TESTING & SECURITY ASSESSMENT-REPORT-

SECURITY ASSESSMENT 

# Networkwalks-B083-Week4-Mediroza-Security Assessment.

> **Educational / Authorized Security Assessment**

A controlled penetration-testing project focused on evaluating the security of a web application, with emphasis on authentication, access control, sensitive-data exposure, database security, and password/hash protection.

⚠️ **All testing described in this repository is intended for authorized and controlled environments only.**

---

## 📌 Project Overview

This project documents a structured penetration-testing assessment performed against the **Mediroza Hospital web application environment**.

The assessment was divided into multiple milestones to identify potential weaknesses affecting:

- Authentication security
- Authorization and access control
- Sensitive information exposure
- Database security
- Password and hash protection
- Web application input handling

All testing activities were performed within an authorized security-assessment scope.

---

## 🎯 Objectives

The primary objectives of this assessment were:

- Identify weaknesses in web application authentication.
- Evaluate access-control mechanisms.
- Assess potential sensitive-data exposure.
- Identify risks associated with exposed database resources or backups.
- Analyze password and hash-storage security.
- Document evidence for each assessment milestone.
- Classify findings according to security impact.
- Provide practical remediation recommendations.

---
